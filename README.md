⚡ Himmah | Task & Productivity Manager
A clean and modern web app for managing daily tasks and ideas, built with gamification features (XP points) to keep you motivated and productive.

🌟 Key Features
Task Management: Add, edit, delete, and mark daily tasks as completed.

Brain Dump: A quick space to capture notes, ideas, and thoughts on the fly.

Gamification (XP Points): Earn XP points every time you complete a task.

Firebase Integration: User authentication (Sign Up / Sign In) and real-time cloud data storage.

Responsive UI: Supports Light/Dark mode and bilingual toggle (Arabic / English).

🛠️ Tech Stack
Front-End: HTML5, CSS3, JavaScript (Vanilla ES6)

Backend: Firebase (Authentication & Realtime Database)

Fonts & Icons: FontAwesome, Google Fonts (Tajawal, Plus Jakarta Sans)
